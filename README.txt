# TacoDiscordBot 利用者向け説明書

このBotは、募集、AI会話、VC滞在時間の集計、コイン、ゲーム、誕生日通知などの機能を提供します。
Discordのチャット欄で「/」を入力すると、利用可能なスラッシュコマンドを確認できます。

## 注意事項
- 一部の機能はサーバー内でのみ利用できます。
- サーバーによっては、利用できる機能や投稿先が設定されていない場合があります。
- 機能を利用できない場合は、表示されたエラーメッセージを確認してください。
- コマンド名や引数名はDiscord上の表示に従って入力してください。

## 1. AI機能

`/ai message:<メッセージ>`

AIに質問やメッセージを送り、回答を受け取ります。
サーバー内で実行した場合、サーバー単位で直前までの会話内容を考慮して回答します。
DMで実行した場合は、会話履歴を使用しない単発の問い合わせとして処理されます。

利用できない場合
- AIサービスが利用できない状態になっている
- AIサービスが混雑または一時停止している

`/aichannel`

現在のチャンネルを、そのサーバーの「AI会話チャンネル」に設定します。
設定後は、そのチャンネルに通常のメッセージを投稿すると、Botが自動的にAIへ送信して回答します。

- サーバー内でのみ利用できます。
- AI会話として扱うチャンネルは、サーバーごとに1つです。
- Bot自身の投稿やWebhookの投稿はAIへの送信対象外です。
- 設定後にそのチャンネルへ投稿すると、BotがAIとして返信します。

## 2. 募集・締め切り

`/bo`

ゲームや作業などの参加者を募集するメッセージを作成します。
入力できる項目はすべて任意です。

**引数**
- `content`：募集内容
- `at`：募集人数。募集主は人数に含まれません。例えば「3」の場合、募集主を含めて4人で募集終了します。
- `rank`：ランクや条件などの表示
- `deadline`：締め切り日時。形式は `yyyy-MM-dd HH:mm` です。
  例：2026-08-13 01:30
- `description`：募集の説明

募集メッセージには、参加、参加取消、募集終了のボタンが表示されます。
募集主は募集を終了できます。参加者が指定人数に達した場合も自動的に終了します。
締め切りを過ぎた場合は自動的に終了し、参加者へ通知されます。

- 募集人数を0または未指定にすると、人数による自動終了はありません。
- 締め切り日時は日本時間として扱われます。
- 締め切りは、募集を作成した後に `/deadline` から設定することもできます。
- 終了した募集には、同じ内容で再募集するボタンが表示されます。
- 締め切り未設定の募集は、作成から7日を超えると自動的に整理されます。

`/deadline`

自分が作成した直近の募集に締め切りを設定します。
表示された画面で、日付・時・分を選択して「決定」を押してください。

- 選択できる日付は、当日から25日分です。
- 時刻は5分単位で選択できます。
- 操作できるのはコマンドを実行した本人だけです。
- 直近の募集が見つからない場合は設定できません。

## 3. 誕生日

`/birthday month:<月> day:<日>`

自分の誕生日を登録または更新します。

**任意の引数**
- `user`：対象ユーザー。未指定の場合は自分が対象です。
- `year`：誕生年。指定すると誕生日メッセージに年齢が表示されます。

- 月は1～12、日は1～31で指定します。
- 実在しない日付は登録できません。
- 誕生年を指定する場合は、1年から現在の年まで指定できます。
- コマンドはサーバー内で利用してください。

`/birthdaychannel`

誕生日メッセージの投稿先を、コマンドを実行したチャンネルに設定します。
誕生日当日の日本時間に、そのチャンネルへお祝いメッセージが投稿されます。

- サーバー内でのみ利用できます。
- 投稿先はサーバーごとに設定されます。

## 4. コインとVC滞在時間

`/status`

自分の現在の情報を表示します。

- ユーザー名
- 所有コイン
- 累計VC滞在時間
- 換金済みのVC滞在時間
- 換金可能なVC滞在時間
- サーバー内のコインランキング順位

`/exchange`

VC滞在時間をコインへ換金します。
換金レートは以下のとおりです。

**6分のVC滞在時間 = 25コイン**

6分未満の端数は、次回の換金まで繰り越されます。
換金前に確認画面が表示されるため、「換金」ボタンを押すと確定します。
「キャンセル」を押すと換金せずに終了します。

- 換金できるのは、未換金のVC滞在時間です。
- 確認画面を操作できるのは実行者だけです。
- 換金済みの時間を再度換金することはできません。

`/pay user:<送信先> coin:<枚数>`

他のユーザーへコインを送信します。

- 送信枚数は1枚以上で指定してください。
- 自分自身には送信できません。
- Botユーザーには送信できません。
- 残高不足の場合は送信されません。
- サーバー内でのみ利用できます。

`/richrank`

サーバー内のコイン保有量ランキングを表示します。
上位10名まで表示されます。Botユーザーはランキング対象外です。

## 5. VC機能

`/vclog`

VCへの参加、退出、チャンネル移動のログ表示を切り替えます。

- 初回実行時：現在のテキストチャンネルをVCログの投稿先に設定します。
- 設定済みの状態で再実行：VCログを無効にします。
- サーバー内でのみ利用できます。

VCログが有効な場合、メンバーのVC参加・退出・チャンネル移動が設定チャンネルに通知されます。

`/vcrank period:<期間>`

VC滞在時間のランキングを表示します。
periodには次のいずれかを指定します。

- `day`：過去24時間
- `week`：過去7日間
- `month`：過去1か月
- `all`：全期間（初期値）

ランキングは最大10位まで表示され、実行者自身の順位も表示されます。
サーバー内でのみ利用できます。

## 6. ブラックジャック

`/blackjack bet:<ベット額>`

コインをベットしてブラックジャックをプレイします。
ベット額は1以上で、所持コイン以内にしてください。

ゲーム開始時にプレイヤーとディーラーへカードが配られます。
ゲーム中はボタンで操作します。

- **HIT**：カードを1枚引く
- **STAND**：カードを引かずに勝負する

勝敗と払い戻し
- **BLACKJACK**：最初の2枚で合計21。ベット額の3倍を払い戻します。
- **勝利**：ベット額の2倍を払い戻します。
- **PUSH（引き分け）**：ベット額をそのまま払い戻します。
- **敗北またはBUST**：払い戻しはありません。

Aは、合計が21を超えない範囲で1または11として扱われます。
同じサーバーで同時にプレイできるゲームは、ユーザー1人につき1つまでです。
ゲームのボタンを操作できるのは、そのゲームを開始した本人だけです。

## 7. スロット

`/slot bet:<ベット額>`

コインをベットしてスロットを回します。
ベット額は1以上で、所持コイン以内にしてください。
3つのリールが約700ミリ秒間隔で順番に表示されます。

**絵柄と払い戻し倍率**
- 🍒：出現率30%、3つ揃い10倍、リーチ0.5倍
- 🍋：出現率22%、3つ揃い18倍、リーチ0.5倍
- 🍇：出現率15%、3つ揃い28倍、リーチ1倍
- 🍉：出現率11%、3つ揃い42倍、リーチ1倍
- 🍈：出現率9%、3つ揃い64倍、リーチ1.5倍
- 💎：出現率6%、3つ揃い100倍、リーチ2倍
- 🔔：出現率5%、3つ揃い300倍、リーチ3倍
- 7️⃣：出現率2%、3つ揃い900倍、リーチ5倍

**判定**
- 同じ絵柄が3つ：3つ揃い倍率で払い戻し
- 同じ絵柄が2つ：リーチ倍率で払い戻し
- すべて異なる：ハズレ。払い戻しなし

払い戻しの小数点以下は切り捨てられます。
ベット額は先に消費され、払い戻しがある場合だけ後から加算されます。

`/slotstatus`

Bot全体で共有されるスロット統計を表示します。

- 累計回転数
- 最長ハマり回数
- 最短当たり回数

## 8. 操作できない場合

次のような場合は、コマンドを実行できない、またはエラーメッセージが表示されます。

- DMでサーバー専用コマンドを実行した
- サーバーで対象機能が利用できる状態になっていない
- コイン残高が不足している
- 入力値や日時の形式が正しくない
- AIなどの外部サービスが一時的に利用できない

問題が続く場合は、コマンド名、入力内容、表示されたエラーメッセージを添えてサーバーの管理者へ連絡してください。
