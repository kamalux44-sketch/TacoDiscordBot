## ■ MINES

### `/mines bet:<額>`

5列×4行の20マスから安全マスを開けます。
ベット額は1以上かつ所持コイン以内です。

* 💣 爆弾は4個です。
* 📈 安全マスを開けるほど倍率が上がります。
* `CASH OUT`で任意のタイミングに回収できます。
* 💥 爆弾を開けるとGAME OVERとなり、払い戻しはありません。
* 🎯 16個すべての安全マスを開けると自動回収されます。

## ■ ラストチャンス

### `/lastchance`

所持コインが0のときに1回だけ利用できる、復活のためのゲームです。
開始すると破産回数が1回増えます。

* 🛡️ **安定**：1,000コインを確実に獲得
* 🎲 **ギャンブル**：0～3,000コイン
* 💎 **一発逆転**：5,000コインまたは0コイン（5%で5,000コイン）

サーバー内でのみ利用できます。

## ■ サーバーイベント

### `/serverevent`

選択画面からサーバーイベントを発動します。
表示される必要コストは、発動時点の実装値に基づきます。

```text
💰 倍返しキャンペーン！
コスト：TOP10合計コインの50%
効果：30分間、ブラックジャック・DOUBLE UP・
      スロット・ルーレットの払い戻しが1.5倍

🎰 激アツスロット×10！
コスト：TOP10合計コインの50%
効果：10分間、以下の出現率に変更
      🍒16% / 🍋14% / 🍇10% / 🍉8%
      🍈10% / 🔔19% / 💎14% / 7️⃣9%

🛡️ 50% BACK保証
コスト：TOP10合計コインの30%
効果：30分間、対象ゲームで負けた場合に
      ベット額の50%を返還

🍀 豪運に幸あれ！
コスト：TOP10合計コインの10%
効果：20分間、ブラックジャック・スロット・
      ルーレットの払い戻しが1.25倍

🪙 ブラックジャック保険
コスト：発動者の所持コインの50%
効果：10分間、サレンダー時に
      ベット額の80%を返還

🔥 倍倍倍プッシュ！！
コスト：20,000コイン
効果：10分間、DOUBLE UPの当選倍率を2.4倍に変更

💣 Mines安全週間1
コスト：発動者の所持コインの20%
効果：10分間、爆弾を1個減少（4個→3個）

💣 Mines安全週間2
コスト：発動者の所持コインの40%
効果：10分間、爆弾を2個減少（4個→2個）

💣 Mines安全週間3
コスト：発動者の所持コインの95%
効果：10分間、爆弾を3個減少（4個→1個）

💎 生きるか死ぬか
コスト：発動者の所持コインの50%
効果：次の1ゲーム限定。
      勝利時は予定払い戻しが5倍、
      敗北時はゲーム後の所持コインの50%を失う
```

* 通常のサーバーイベントは、同時に1つだけ発動できます。
* 「生きるか死ぬか」は個人イベントのため、サーバーイベントと同時に発動できます。
* 発動コストの割合は、発動者またはサーバー内TOP10の所持コインを基準に計算します。

## ■ 管理・通知設定

### `/rolechannel`

ロール解除通知の投稿先を、実行したチャンネルに設定します。
管理者のみ利用できます。

## ■ 主な制限

* サーバー専用コマンドをDMで実行することはできません。
* ベットや送金には残高が必要です。
* 入力値や日時形式が不正な場合はエラーになります。
* ゲーム中は同じゲームを重複して開始できません。
* ゲームのボタンを操作できるのは開始者本人です。
* 外部サービス障害時はAI機能を利用できません。
